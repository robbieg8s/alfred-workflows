This workflow provides a ` search which lets you choose a tab from a supported browser, and copies the tab location to the clipboard.

The workflow shows browser tabs by title which can be filtered by typing as usual. The subtitle shows the host of the tab, plus brief help. Actioning an item places the url of the tab on the clipboard as plain text.

Holding Command (⌘) while actioning the item removes the query string and fragment - i.e. everything after the `?` - from the url before copying it. Holding Option (⌥), aka Alt, while actioning the item removes just the fragment - i.e. everything after the `#` - from the url before copying it.
